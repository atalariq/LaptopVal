# BLUEPRINT — Used Laptop Deal Evaluator

## Project Identity

**Name:** Used Laptop Deal Evaluator (Perlu explorasi, terlalu panjang; rebranding biar lebih catchy)
**Tagline:** "Kriteria beli laptop bekas yang eksplisit dan konsisten." (Perlu explorasi, AI-ish banget)
**Problem:** Teman-teman sering tanya laptop bekas worth it atau enggak. Jawabannya sering subjektif. App ini bikin kriterianya eksplisit, transparan, dan konsisten.
**Stack:** Native PHP + MySQL + Vanilla JS + HTML/CSS
**No frameworks:** Laravel, CodeIgniter, React, Vue — semua prohibited. Kecuali framework CSS kayak Bootstrap atau Tailwind

---

## MVP Scope

**In scope:**
- Admin login/logout (session-based)
- Admin CRUD: brands, laptops, use_cases, scoring_rules
- System auto-calculates score + verdict on laptop INSERT/UPDATE (via trigger)
- Public: browse listings dengan verdict badge
- Public: detail page dengan score breakdown
- Public: filter laptop by use case
- Admin dashboard: avg score per brand, total listings

**Non-goals (explicitly excluded):**
- Public registration / user reviews
- Image upload
- GPU scoring / benchmark API
- Real-time price scraping
- AI integration
- Marketplace comparison
- Complex use-case recommendation engine
- D3.js / graph visualization

## Database Schema

```sql
-- 1. users
CREATE TABLE users (
  id         INT PRIMARY KEY AUTO_INCREMENT,
  username   VARCHAR(50) UNIQUE NOT NULL,
  password   VARCHAR(255) NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 2. brands
CREATE TABLE brands (
  id    INT PRIMARY KEY AUTO_INCREMENT,
  name  VARCHAR(50) UNIQUE NOT NULL,
  notes TEXT
);

-- 3. laptops
CREATE TABLE laptops (
  id           INT PRIMARY KEY AUTO_INCREMENT,
  brand_id     INT NOT NULL,
  model        VARCHAR(100) NOT NULL,
  release_year YEAR NOT NULL,
  cpu_tier     TINYINT NOT NULL,    -- 1=low, 2=mid, 3=high
  ram_gb       TINYINT NOT NULL,
  storage_gb   SMALLINT NOT NULL,
  condition    TINYINT NOT NULL,    -- 1=buruk, 2=cukup, 3=baik, 4=mulus
  has_warranty BOOLEAN DEFAULT FALSE,
  price        INT NOT NULL,        -- ribuan IDR, e.g. 3500 = Rp3.5jt
  listed_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (brand_id) REFERENCES brands(id)
);

-- 4. scoring_rules (seed data, shown in UI for transparency)
CREATE TABLE scoring_rules (
  id          INT PRIMARY KEY AUTO_INCREMENT,
  factor      VARCHAR(50) NOT NULL,   -- 'cpu_tier', 'ram_gb', 'condition', dll
  value_key   VARCHAR(50) NOT NULL,   -- '3', '16', '4', dll
  points      TINYINT NOT NULL,
  description VARCHAR(100)
);

-- 5. use_cases
CREATE TABLE use_cases (
  id           INT PRIMARY KEY AUTO_INCREMENT,
  name         VARCHAR(50) NOT NULL,  -- 'Office', 'Kuliah', 'Edit Video', dll
  min_ram_gb   TINYINT NOT NULL,
  min_cpu_tier TINYINT NOT NULL,
  min_storage  SMALLINT NOT NULL
);

-- 6. evaluations (1 per laptop, auto-generated by trigger)
CREATE TABLE evaluations (
  id           INT PRIMARY KEY AUTO_INCREMENT,
  laptop_id    INT UNIQUE NOT NULL,
  value_score  TINYINT NOT NULL,       -- 0-100
  verdict      VARCHAR(20) NOT NULL,   -- 'Great Deal','Fair','Overpriced','Avoid'
  evaluated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (laptop_id) REFERENCES laptops(id) ON DELETE CASCADE
);
```

## Scoring Model

```
value_score = cpu_score + ram_score + storage_score + condition_score
              + warranty_bonus + age_penalty + price_score

Max = 100
```

| Faktor       | Logika                                        | Max poin |
|--------------|-----------------------------------------------|----------|
| cpu_tier     | tier×10 (1=10, 2=20, 3=30)                   | 30       |
| ram_gb       | <8→5, 8→10, 16→20, ≥32→25                   | 25       |
| storage_gb   | <256→3, 256→7, 512→12, ≥1000→15             | 15       |
| condition    | (nilai-1)×5 (1=0, 2=5, 3=10, 4=15)          | 15       |
| has_warranty | true→5                                        | 5        |
| age_penalty  | <2018→-5, <2020→-2, ≥2020→0                 | -5       |
| price_score  | hardcode 10 (neutral), refine if time allows  | 10       |

**Verdict mapping:**

| Score  | Verdict     |
|--------|-------------|
| ≥75    | Great Deal  |
| 55–74  | Fair        |
| 35–54  | Overpriced  |
| <35    | Avoid       |

## MySQL Functions

```sql
-- fn_get_verdict
CREATE FUNCTION fn_get_verdict(score TINYINT)
RETURNS VARCHAR(20) DETERMINISTIC
BEGIN
  IF score >= 75 THEN RETURN 'Great Deal';
  ELSEIF score >= 55 THEN RETURN 'Fair';
  ELSEIF score >= 35 THEN RETURN 'Overpriced';
  ELSE RETURN 'Avoid';
  END IF;
END;

-- fn_calculate_score
CREATE FUNCTION fn_calculate_score(
  cpu_tier TINYINT, ram_gb TINYINT, storage_gb SMALLINT,
  cond TINYINT, warranty BOOLEAN, release_year YEAR, price INT
)
RETURNS TINYINT DETERMINISTIC
BEGIN
  DECLARE score INT DEFAULT 0;
  SET score = score + (cpu_tier * 10);
  IF ram_gb >= 32 THEN SET score = score + 25;
  ELSEIF ram_gb >= 16 THEN SET score = score + 20;
  ELSEIF ram_gb >= 8 THEN SET score = score + 10;
  ELSE SET score = score + 5; END IF;
  IF storage_gb >= 1000 THEN SET score = score + 15;
  ELSEIF storage_gb >= 512 THEN SET score = score + 12;
  ELSEIF storage_gb >= 256 THEN SET score = score + 7;
  ELSE SET score = score + 3; END IF;
  SET score = score + ((cond - 1) * 5);
  IF warranty THEN SET score = score + 5; END IF;
  IF release_year < 2018 THEN SET score = score - 5;
  ELSEIF release_year < 2020 THEN SET score = score - 2; END IF;
  SET score = score + 10;
  RETURN LEAST(GREATEST(score, 0), 100);
END;
```

## MySQL Triggers

```sql
-- T1: Auto-insert evaluation setelah laptop baru
CREATE TRIGGER trg_after_laptop_insert
AFTER INSERT ON laptops
FOR EACH ROW
BEGIN
  DECLARE v_score TINYINT;
  SET v_score = fn_calculate_score(
    NEW.cpu_tier, NEW.ram_gb, NEW.storage_gb,
    NEW.condition, NEW.has_warranty, NEW.release_year, NEW.price
  );
  INSERT INTO evaluations (laptop_id, value_score, verdict)
  VALUES (NEW.id, v_score, fn_get_verdict(v_score));
END;

-- T2: Auto-update evaluation kalau laptop diedit
CREATE TRIGGER trg_after_laptop_update
AFTER UPDATE ON laptops
FOR EACH ROW
BEGIN
  DECLARE v_score TINYINT;
  SET v_score = fn_calculate_score(
    NEW.cpu_tier, NEW.ram_gb, NEW.storage_gb,
    NEW.condition, NEW.has_warranty, NEW.release_year, NEW.price
  );
  UPDATE evaluations
  SET value_score = v_score,
      verdict     = fn_get_verdict(v_score),
      evaluated_at = NOW()
  WHERE laptop_id = NEW.id;
END;
```

## Views

```sql
CREATE VIEW v_laptop_evaluations AS
SELECT l.id, l.model, b.name AS brand, l.price,
       l.ram_gb, l.storage_gb, l.condition, l.has_warranty,
       l.release_year, e.value_score, e.verdict, e.evaluated_at
FROM laptops l
JOIN brands b ON l.brand_id = b.id
JOIN evaluations e ON e.laptop_id = l.id;

CREATE VIEW v_best_value_laptops AS
SELECT * FROM v_laptop_evaluations
WHERE verdict IN ('Great Deal', 'Fair')
ORDER BY value_score DESC;
```

## Complex Queries (min 3)

```sql
-- Q1: Semua laptop dengan brand + verdict (JOIN)
SELECT l.model, b.name AS brand, e.value_score, e.verdict
FROM laptops l
JOIN brands b ON l.brand_id = b.id
JOIN evaluations e ON e.laptop_id = l.id
ORDER BY e.value_score DESC;

-- Q2: Laptop cocok untuk use case tertentu (JOIN + filter)
SELECT l.model, b.name AS brand, e.verdict, l.price
FROM laptops l
JOIN brands b ON l.brand_id = b.id
JOIN evaluations e ON e.laptop_id = l.id
JOIN use_cases u ON u.id = ?
WHERE l.ram_gb >= u.min_ram_gb
  AND l.cpu_tier >= u.min_cpu_tier
  AND l.storage_gb >= u.min_storage
ORDER BY e.value_score DESC;

-- Q3: Rata-rata score per brand (GROUP BY + HAVING)
SELECT b.name, ROUND(AVG(e.value_score), 1) AS avg_score,
       COUNT(*) AS total_listings
FROM brands b
JOIN laptops l ON l.brand_id = b.id
JOIN evaluations e ON e.laptop_id = l.id
GROUP BY b.id
HAVING COUNT(*) > 0
ORDER BY avg_score DESC;
```

## Risks & Scope Control

| Risiko                          | Mitigasi                                              |
|---------------------------------|-------------------------------------------------------|
| Scoring terlalu kompleks        | Ikuti rumus di blueprint ini, jangan tambah faktor baru |
| price_score butuh kalkulasi rumit | Hardcode 10 poin neutral dulu, refine kalau ada waktu |
| Trigger gagal di MySQL lama     | Test di MySQL 8+, pastikan DELIMITER diset benar      |
| UI kehabisan waktu              | Component cards + badges sudah cukup, skip custom CSS |
| Scope creep                     | Setiap fitur baru tanya: "Apakah ini wajib untuk UAS?" |
